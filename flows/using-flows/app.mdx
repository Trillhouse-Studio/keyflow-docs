All flows in keyflow are automatically converted to apps by default. Instead of understanding blocks and connections, users get a clean interface where they input data and get results - no technical knowledge required.

## What Is App View?

App view takes any workflow and creates an application interface for it. Your complex automation becomes as simple as filling out a form and clicking a button.

<Frame>
  <img src="/images/app/app-interface-example.png" alt="Workflow displayed as a clean app interface" />
</Frame>

This is perfect when you want to share your intelligent processes with non-technical team members, or when you need to run the same workflow repeatedly with different inputs.

## Creating an App Interface

### Setting Up Inputs and Outputs

Keyflow automatically generates an app interface based on your workflow's inputs and outputs. Define clear input blocks at the start of your flow and output blocks at the end.

<Frame>
  <img src="/images/app/input-output-setup.png" alt="Configuring inputs and outputs for app view" />
</Frame>

The app interface will create:

- **Input forms** for text, numbers, file uploads, and selections
- **Output displays** for results, generated content, and processed data
- **Progress tracking** so users know the workflow is running

### Designing the User Experience

Configure your input blocks with clear labels and descriptions. This text becomes the user interface, so make it helpful for your intended users.

<Frame>
  <img src="/images/app/input-configuration.png" alt="Configuring input labels and descriptions" />
</Frame>

Good input design makes your app intuitive - users should understand exactly what to provide and what they'll get back.

## App Customization

Make your app feel professional and on-brand with customization options:

### Visual Branding

- **App Icon**: Upload a custom icon that represents your workflow
- **Background Image**: Set a background that matches your brand or purpose
- **Title and Description**: Clear naming that explains what the app does

<Frame>
  <img src="/images/app/app-customization.png" alt="App customization interface showing branding options" />
</Frame>

### App Settings

- **Access Controls**: Determine who can use your app
- **Usage Limits**: Set boundaries on how often the app can be run
- **Result Storage**: Configure how long outputs are kept

## Using Your App

### Running Workflows

Using your app is straightforward - users fill out the input form and click run. The workflow executes in the background while users see a clean progress indicator.

  <img src="/images/app/app-in-use.png" alt="User running a workflow through the app interface" />

### Multiple Runs and History

Users can create new runs while viewing results from previous ones. The app keeps track of all executions, making it easy to compare results or re-run with different inputs.

## Monitoring App Runs

### Run Management Sidebar

The sidebar shows all runs for your app, with status indicators and quick access to results. Users can:

- **View all runs** in chronological order
- **Filter by status** (running, completed, failed)
- **Quick preview** results without opening full details
- **Re-run** previous configurations with one click

<Frame>
  <img src="/images/app/runs-sidebar.png" alt="Sidebar showing all app runs with status and results" />
</Frame>

### Switching Between Views

Toggle between creating new runs and reviewing previous ones. The interface remembers your input preferences, making it fast to run similar processes repeatedly.

### Real-Time Monitoring

When multiple people use your app simultaneously, everyone can monitor their own runs independently. No conflicts or confusion about whose results are whose.

## Sharing Apps with Teams

### Team Access

Share your app with specific team members or make it available to your entire organization. Users don't need to understand how the workflow works - they just use the app interface.

<Frame>
  <img src="/images/app/team-sharing.png" alt="Sharing app with team members" />
</Frame>

### Collaboration Benefits

Apps enable self-service automation. Instead of running workflows for others, you build the app once and let people use it themselves. This scales your expertise across the entire team.

### Usage Analytics

Track how often your app gets used, which inputs are most common, and where users might be struggling. This helps you improve the workflow and app experience over time.

## Best Practices

### Clear Documentation

- Write helpful descriptions for all inputs
- Include examples of good input formats
- Explain what the output will contain

### Error Handling

- Test your workflow with various input types
- Provide clear error messages when things go wrong
- Include validation to catch common mistakes

### Performance Optimization

- Keep workflows efficient for good app responsiveness
- Consider breaking complex processes into multiple apps
- Use appropriate batch sizes for file processing
