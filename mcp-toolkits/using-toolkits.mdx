Once you've created your MCP toolkit, you can connect it to various applications that support the MCP protocol. Each application has its own connection process, but they all use the same toolkit URL that Keyflow provides.

## Connecting to Claude

Claude supports MCP toolkits through its desktop application. Add your toolkit to extend Claude's capabilities with your custom workflows.

<Frame>
  <img src="/images/toolkits/claude-connection.png" alt="Adding MCP toolkit to Claude desktop app" />
</Frame>

### Connection Steps for Claude

1. **Open Claude desktop app** and go to settings
2. **Find the MCP section** in the configuration
3. **Add a new server** using your toolkit URL
4. **Name your toolkit** for easy identification
5. **Test the connection** to ensure it's working

Once connected, Claude can use your workflows as tools during conversations, calling them automatically when relevant to the task at hand.

## Connecting to Claude Code

Claude Code integrates with MCP toolkits to bring custom automation into your coding workflow through the terminal.

### Connection Steps for Claude Code

1. **Install Claude Code** if you haven't already
2. **Configure MCP settings** in your Claude Code configuration
3. **Add your toolkit URL** to the server list
4. **Restart Claude Code** to load the new tools
5. **Verify tools are available** in your coding sessions

Your workflows become available as commands that Claude Code can execute while helping with development tasks.

## Connecting to Cursor

Cursor's MCP integration lets you bring workflow automation directly into your development environment.

<Frame>
  <img src="/images/toolkits/cursor-connection.png" alt="Configuring MCP toolkit in Cursor IDE" />
</Frame>

### Connection Steps for Cursor

1. **Open Cursor settings** and navigate to extensions
2. **Find MCP configuration** in the settings menu
3. **Add your server URL** from Keyflow
4. **Configure toolkit name** and description
5. **Reload Cursor** to activate the tools

Your workflows integrate seamlessly into Cursor's AI-powered development features.

## Connecting to Windsurf

Windsurf supports MCP toolkits for enhanced development workflows and automation.

### Connection Steps for Windsurf

1. **Access Windsurf settings** through the preferences menu
2. **Locate MCP integrations** section
3. **Add new server** with your toolkit URL
4. **Set toolkit preferences** and permissions
5. **Restart Windsurf** to complete integration

## Verifying Your Connection

After connecting to any MCP client, verify that your toolkit is working correctly:

### Check Tool Availability

Confirm that your workflows appear as available tools in the connected application. They should be listed with the names and descriptions you configured.

### Test Tool Execution

Try using one of your simpler tools to ensure the connection is working and data flows correctly between the application and your workflows.

### Monitor Performance

Watch how your tools perform in the connected environment and check for any errors or unexpected behavior.

## Using Tools Effectively

### Natural Integration

Once connected, your tools work as part of the application's natural workflow. AI models will automatically choose when to use your tools based on the task context.

### Tool Discovery

Applications typically show available tools in their interface, making it easy for users to discover and understand what custom functionality is available.

### Seamless Experience

Well-designed toolkits feel like native features of the connected application rather than external add-ons.

## Troubleshooting Connections

### Common Issues

- **URL problems**: Verify you're using the correct toolkit URL from Keyflow
- **Network access**: Ensure the application can reach Keyflow servers
- **Configuration errors**: Double-check MCP settings in the target application
- **Tool conflicts**: Make sure tool names don't conflict with existing functionality

### Getting Help

If you encounter connection issues, check the documentation for your specific MCP client or contact Keyflow support for assistance with toolkit configuration.
