Most business processes are just patterns - read documents, analyze data, make decisions, update systems.

<Tip>
Instead of doing this manually over and over, you build smart processes that handle it automatically.
</Tip>

Think of it as connecting blocks that each do something specific: analyze text with AI, pull data from APIs, send emails, or request human input for complex decisions. These processes can include both AI and human intelligence in the loop - letting you automate what's routine while keeping humans involved where judgment matters.

Once built, you can deploy these flows as internal apps, trigger them via APIs, or integrate them with existing systems using automation triggers. 

<Tip> Build the process once, use it everywhere. </Tip>
