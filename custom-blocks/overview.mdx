## What Are Custom Blocks?

Custom blocks let power users and developers push beyond the boundaries of what's possible with pre-built blocks. While no-code tools are powerful, they eventually hit limitations. Custom blocks solve this by letting you write custom code and bring it directly into the Keyflow canvas.

With custom blocks, you can build truly powerful agentic systems that combine the ease of visual workflows with the unlimited flexibility of custom code.

## Why Custom Blocks Matter

No-code tools are great for getting started quickly, but every business has unique needs that require custom solutions. Custom blocks bridge this gap by letting you:

- **Integrate with proprietary systems** that don't have pre-built blocks
- **Implement complex business logic** that requires custom algorithms
- **Build specialized AI workflows** with custom model integrations
- **Create reusable components** for your team's specific processes

This means you get the best of both worlds - visual workflow building for standard operations and unlimited customization where you need it.

## How Custom Blocks Work

Custom blocks are built using the Keyflow SDK and deployed as block servers. Here's the basic flow:

1. **Build blocks** using our SDK with your custom code
2. **Create a block server** that hosts your custom blocks
3. **Deploy the server** either self-hosted or through Keyflow hosting
4. **Connect to your workspace** using your workspace API key
5. **Use blocks** from the block library like any other block

## Hosting Options

### Self-Hosting

Host your block servers on your own infrastructure for maximum control and security. This is ideal for enterprise environments or when working with sensitive data.

### Keyflow Hosting

We can host your block servers for you, handling all the infrastructure and maintenance. This option provides the simplicity of managed hosting while still giving you the power of custom code.

## What You Can Build

Custom blocks open up unlimited possibilities:

- **Advanced data processing** with specialized algorithms
- **Custom AI integrations** with proprietary models
- **Enterprise system connectors** for internal tools
- **Complex workflow logic** that requires programming
- **Specialized file processing** for unique formats
- **Custom API integrations** with any external service
