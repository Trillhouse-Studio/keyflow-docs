### Overview

The Ask Image block allows you to analyze images using advanced AI vision models. Upload an image and ask questions about its contents, get detailed descriptions, extract text, or perform visual analysis tasks.

<Tip>Analyze images with AI to extract insights, identify objects, read text, and answer visual questions.</Tip>

---

### Inputs

<ParamField query="File name" type="file" required>
  The image file you want to analyze. Supports common image formats like PNG, JPG, JPEG, and GIF.
</ParamField>

<ParamField query="Prompt" type="string" required>
  Describe the analysis you want to perform on the image. Be specific about what you want to know or extract.
</ParamField>

<br></br>

<Accordion title="Advanced Settings">
  <ParamField query="Model" type="string" default="gpt-4-vision-preview">
    The AI model to use for image analysis. Choose based on your needs for accuracy and capabilities.
  </ParamField>

  <ParamField query="Cache Response" type="boolean" default="true">
    If checked, the model response will be cached for future use to save costs on identical requests.
  </ParamField>

  <ParamField query="Account" type="credential">
    Select the API credentials you want to use for the chosen model provider.
  </ParamField>
</Accordion>

### Outputs

<ParamField query="Answer" type="string">
  The AI-generated response to your prompt about the image, containing the analysis or information you requested.
</ParamField>

<br></br>

### Best Practices

<Steps>
  <Step title="Write Clear, Specific Prompts">
    Be detailed and specific about what you want the AI to analyze or extract from the image.
    
    ```text ⚠️ Bad Example wrap
    What do you see?
    ```
    
    ```text ✅ Good Example wrap
    List all the objects you see in this image, including their colors and approximate positions. Also identify any text that appears in the image.
    ```
  </Step>

  <Step title="Choose the Right Model">
    Select models based on your specific needs - some excel at text extraction, others at detailed visual analysis.
  </Step>

  <Step title="Optimize Image Quality">
    Use high-quality, well-lit images for better analysis results. Ensure text is readable and objects are clearly visible.
  </Step>
</Steps>

### Troubleshooting

<AccordionGroup>
  <Accordion title="Why is my image not being processed?">
    Check that your image file is in a supported format and not corrupted.
    
    Supported formats:
    - PNG
    - JPG/JPEG 
    - GIF
    - WebP (some models)
    
    <Warning>Very large images may exceed model limits and need to be resized</Warning>
  </Accordion>

  <Accordion title="The AI can't read text in my image">
    <Tip>Ensure text in the image is clear, well-lit, and not too small</Tip>
    
    Try these solutions:
    1. Use higher resolution images for small text
    2. Ensure good contrast between text and background
    3. Ask specifically for text extraction in your prompt
    4. Try different models - some are better at OCR tasks
  </Accordion>

  <Accordion title="Response is too generic or inaccurate">
    Improve your prompts to get more specific and accurate responses:
    
    <Info>More specific prompts lead to more detailed and accurate analysis</Info>
    
    1. Ask for specific details rather than general descriptions
    2. Break complex questions into multiple simpler ones
    3. Mention what type of image it is (photo, diagram, screenshot, etc.)
    4. Specify the format you want the response in
  </Accordion>

  <Accordion title="High costs for image analysis">
    <Warning>Vision models typically cost more than text-only models due to image processing</Warning>
    
    To optimize costs:
    1. Enable caching for repeated analysis of the same images
    2. Use more efficient models for simple tasks
    3. Resize very large images before processing
    4. Batch similar questions in a single prompt when possible
  </Accordion>

  <Accordion title="Model says it cannot see the image">
    This usually indicates an issue with image format or upload:
    
    1. Verify the image uploaded successfully to Keyflow
    2. Check that the file is a valid image format
    3. Try re-uploading the image
    4. Ensure the image file isn't corrupted
    
    <Info>Some models have specific requirements for image formats and sizes</Info>
  </Accordion>
</AccordionGroup>
