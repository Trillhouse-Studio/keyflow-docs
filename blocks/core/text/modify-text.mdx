---
title: Modify Text
---

### Overview

Apply standardized formatting transformations to text strings. Choose from five different formatting options to clean up, standardize, or modify your text data.

<Tip>Perfect for data cleaning, standardizing user inputs, and preparing text for consistent display or processing.</Tip>

---

### Inputs

<ParamField query="Value" type="string" required>
  The text string you want to format or modify.
</ParamField>

<ParamField query="Formatter" type="string" default="Trim Spaces">
  The formatting operation to apply to your text. Choose from:
  - **Trim Spaces**: Remove leading and trailing whitespace
  - **To Lowercase**: Convert all letters to lowercase
  - **To Uppercase**: Convert all letters to uppercase  
  - **To Propercase**: Capitalize the first letter of each word
  - **Truncate**: Cut text to a specified length
</ParamField>

<br></br>

<Accordion title="Advanced Settings">
  <ParamField query="Max Num Tokens" type="number">
    Maximum number of characters to keep when using "Truncate" formatter. Only appears when Truncate is selected.
  </ParamField>
</Accordion>

### Outputs

<ParamField query="formatted_value" type="string">
  The text after applying the selected formatting operation.
</ParamField>

---

### Best Practices

<Steps>
  <Step title="Choose the Right Formatter for Your Data">
    Select the formatter that matches your data cleaning needs and downstream processing requirements.
    ```text ⚠️ Bad Example wrap
    Using "To Uppercase" for email addresses: "USER@EXAMPLE.COM"
    ```
    ```text ✅ Good Example wrap
    Using "To Lowercase" for email addresses: "user@example.com"
    ```
  </Step>

  <Step title="Use Trim Spaces First for User Input">
    Always trim spaces when processing user-generated content to remove accidental whitespace.
  </Step>

  <Step title="Set Appropriate Truncate Limits">
    When truncating text, choose character limits that preserve meaning while meeting your display requirements.
    ```text ⚠️ Bad Example wrap
    Truncating "Hello World!" to 5 characters: "Hello"
    ```
    ```text ✅ Good Example wrap
    Truncating "Hello World!" to 11 characters: "Hello World"
    ```
  </Step>
</Steps>

### Troubleshooting

<AccordionGroup>
  <Accordion title="Why is my truncated text cut off mid-word?">
    The Truncate formatter counts characters, not words. It will cut text exactly at the specified character limit.
    
    <Tip>If you need word-based truncation, consider using a larger character limit or processing the text further to remove partial words.</Tip>
  </Accordion>

  <Accordion title="What happens with empty or null input values?">
    The block requires a valid input string. Empty strings will be processed according to the selected formatter, but null or undefined values will cause an error.
    
    <Warning>Always ensure your input has a valid string value before connecting to this block.</Warning>
  </Accordion>

  <Accordion title="How does Propercase handle special characters and punctuation?">
    Propercase capitalizes letters that come after spaces. Other punctuation marks don't trigger capitalization.
    
    <Info>For example: "hello-world test" becomes "Hello-world Test" (only space triggers capitalization)</Info>
  </Accordion>
</AccordionGroup>
