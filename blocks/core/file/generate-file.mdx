title: Generate File
---

### Overview

Creates files from text content in multiple formats including PDF, DOCX, TXT, CSV, and Markdown. Perfect for converting text data into downloadable documents or files for external sharing.

<Tip>Transform any text content into professional documents with support for 5 popular file formats.</Tip>

---

### Inputs

<ParamField query="File Name" type="string" required>
  The name of the file to be created (without the file extension). Maximum 100 characters allowed.
</ParamField>

<ParamField query="File Contents" type="string" required>
  The text content that will be saved in the generated file. Cannot be empty.
</ParamField>

<ParamField query="File Type" type="string" default=".txt">
  The format for your generated file. Available options: `.pdf`, `.docx`, `.txt`, `.csv`, `.md`
</ParamField>

### Outputs

<ParamField query="generated_file_name" type="file">
  The generated file containing your content in the specified format, ready for download or further processing.
</ParamField>

### Troubleshooting

<AccordionGroup>
  <Accordion title="Why is my file name showing an error?">
    File names must be 100 characters or less and cannot be empty. The file extension will be automatically added based on your selected file type.
    
    ```text Example Solution wrap
    Instead of: "MyVeryLongFileNameThatExceedsTheMaximumAllowedCharacterLimitAndWillCauseAnErrorWhenTryingToGenerate"
    Use: "report_summary_2024"
    ```
  </Accordion>

  <Accordion title="Why is my generated file empty or corrupted?">
    <Tip>Ensure your file contents are not empty and are properly formatted for the target file type</Tip>
    File contents cannot be empty. For CSV files, ensure proper comma separation. For markdown files, use valid markdown syntax.
    <Warning>PDF and DOCX generation may fail with extremely large content due to memory limitations</Warning>
  </Accordion>

  <Accordion title="Which file format should I choose for my content?">
    Choose based on your specific needs and how the file will be used:
    
    <Info>
    - `.pdf`: Professional documents, reports, forms that need consistent formatting
    - `.docx`: Editable documents for collaboration or further editing
    - `.txt`: Simple text content, logs, or basic notes
    - `.csv`: Structured data, spreadsheet-compatible format
    - `.md`: Documentation, README files, or content with formatting
    </Info>
  </Accordion>

  <Accordion title="Can I include special characters or formatting in my content?">
    Yes, but formatting support varies by file type. PDF and DOCX support basic text formatting, while TXT files are plain text only. For CSV files, avoid commas in content unless properly escaped.
  </Accordion>

  <Accordion title="What happens if my file name already includes the extension?">
    The block automatically handles file extensions. If your file name already includes the extension (e.g., "report.pdf"), it won't be duplicated. The system ensures the correct extension matches your selected file type.
  </Accordion>
</AccordionGroup>
