---
title: Read File
---

### Overview

Extract the complete text content from uploaded files and transform it into a usable string format for further processing in your workflow.

<Tip>Perfect for reading configuration files, documents, data files, and any text-based content that needs to be processed by other blocks.</Tip>

---

### Inputs

<ParamField query="File name" type="file" required>
  The file you want to read and extract text content from. Select from files previously uploaded to your workspace or files generated by other blocks in your workflow.
</ParamField>

### Outputs

<ParamField query="file_contents" type="string">
  The complete text content of the file formatted as a UTF-8 string, ready for processing by other blocks.
</ParamField>

---

### Best Practices

<Steps>
  <Step title="Use Supported File Types">
    Ensure your file is in one of the supported formats for optimal text extraction.
    ```text ⚠️ Bad Example wrap
    Uploading .exe or .zip files expecting text content
    ```
    ```text ✅ Good Example wrap
    Using .pdf, .csv, .txt, .html, .json, .md, or .docx files
    ```
  </Step>

  <Step title="Verify File Content">
    Check that your files contain readable text content before processing them through the workflow.
  </Step>

  <Step title="Handle Large Files Carefully">

  </Step>
</Steps>

### Troubleshooting

<AccordionGroup>
  <Accordion title="Why am I getting an 'Invalid Space' error?">
    This error occurs when the block cannot access the workspace where your file is stored.
    
    **Solution:** Ensure you're running the workflow in the correct workspace where the file was uploaded.
  </Accordion>

  <Accordion title="What file types are supported?">
    <Tip>The Read File block supports 7 common file formats</Tip>
    
    Supported formats:
    1. **PDF** (.pdf) - Extracts text from PDF documents
    2. **CSV** (.csv) - Reads comma-separated value files
    3. **Text** (.txt) - Plain text files
    4. **HTML** (.html) - Web pages and HTML documents
    5. **JSON** (.json) - JavaScript Object Notation files
    6. **Markdown** (.md) - Markdown formatted text
    7. **Word** (.docx) - Microsoft Word documents
  </Accordion>

  <Accordion title="Why is my file content empty or corrupted?">
    This usually happens with unsupported file types or binary files that don't contain readable text.
    
    <Warning>Binary files like images, executables, or compressed files cannot be read as text</Warning>
    
    **Solutions:**
    1. Verify your file contains actual text content
    2. Check if the file format is in the supported list
    3. For PDFs, ensure they contain searchable text (not scanned images)
    4. For Word documents, use .docx format instead of older .doc format
  </Accordion>

  <Accordion title="How do I handle files generated by previous blocks?">
    When using files created by other blocks in your workflow, make sure the file generation is complete before reading.
    
    <Info>Connect the output of file-generating blocks directly to the File name input</Info>
    
    This ensures proper sequencing and file availability.
  </Accordion>

  <Accordion title="What happens with very large files?">
    Large files may take longer to process and could impact workflow performance.
    
    **Best practices for large files:**
    1. Consider chunking large documents using text processing blocks
    2. Monitor workflow execution time
    3. Use file size limits appropriate for your use case
  </Accordion>
</AccordionGroup>
