---
title: Flatten List
---

### Overview

Converts nested arrays into a single-level array, simplifying complex data structures for easier processing and analysis.

<Tip>Perfect for transforming multi-dimensional data into a flat, workable format.</Tip>

---

### Inputs

<ParamField query="List of List" type="any[ ][ ]" required>
  The nested list structure you want to flatten into a single level. Can contain arrays of any depth with mixed data types.
</ParamField>

### Outputs

<ParamField query="list" type="any[ ]">
  A single-level array containing all elements from the nested structure, preserving the original order and data types.
</ParamField>

---

### Best Practices

<Steps>
  <Step title="Understand Your Data Structure">
    Know the depth and content of your nested arrays before flattening to ensure expected results.
    ```text ⚠️ Bad Example wrap
    Flattening unknown data structure without validation
    ```
    ```text ✅ Good Example wrap
    First inspect your nested array structure, then apply flatten
    ```
  </Step>

  <Step title="Handle Empty Arrays Gracefully">
    Consider how empty nested arrays should be treated in your workflow.
  </Step>

  <Step title="Preserve Data Types">

  </Step>
</Steps>

### Troubleshooting

<AccordionGroup>
  <Accordion title="Why am I getting an error about invalid input?">
    The input must be an array of arrays. Single-level arrays or non-array inputs will cause an error.
    
    ```json Example Solution wrap
    {
      "input_list": [
        ["item1", "item2"],
        ["item3", "item4"]
      ]
    }
    ```
  </Accordion>

  <Accordion title="What happens to deeply nested arrays?">
    <Tip>The flatten operation works recursively on all levels</Tip>
    The block flattens arrays to infinite depth, meaning even deeply nested structures like `[[[["item"]]]]` will be completely flattened to `["item"]`.
  </Accordion>

  <Accordion title="How are mixed data types handled?">
    All original data types are preserved during flattening. Numbers stay numbers, strings stay strings, and objects remain intact.
    
    <Info>The order of elements is maintained from left to right, top to bottom</Info>
  </Accordion>

  <Accordion title="What if my nested array contains null or undefined values?">
    Null and undefined values are preserved in their original positions within the flattened result.
    
    <Warning>Empty arrays within the nested structure will disappear after flattening</Warning>
  </Accordion>
</AccordionGroup>
