---
title: Join Text List
---

### Overview

Combines multiple text items from a list into a single string with customizable separators. This block is perfect for merging individual text elements into formatted output strings.

<Tip>Ideal for creating comma-separated lists, bullet points, or any formatted text output from multiple inputs.</Tip>

---

### Inputs

<ParamField query="Text List" type="string[]" required>
  The list of text items to combine into a single string.
</ParamField>

<ParamField query="Join Characters" type="string" default="">
  Characters used to separate each text item in the final output. Leave empty to join without separators.
</ParamField>

<br></br>

<Accordion title="Advanced Settings">
  <ParamField query="Join By New Line" type="boolean" default="false">
    When enabled, each text item will be separated by a new line instead of the join characters. This setting takes priority over join characters.
  </ParamField>
</Accordion>

### Outputs

<ParamField query="joined_string" type="string">
  The combined text string with all list items joined using the specified separator.
</ParamField>

---

### Best Practices

<Steps>
  <Step title="Choose Appropriate Separators">
    Select separators that match your intended output format and use case.
    
    ```text ⚠️ Bad Example wrap
    Using complex separators: " --> NEXT ITEM --> "
    ```
    
    ```text ✅ Good Example wrap
    Using simple separators: ", " or " | " or just " "
    ```
  </Step>

  <Step title="Handle Empty Lists">
    Always ensure your text list contains items before joining to avoid unexpected empty outputs.
  </Step>

  <Step title="Consider Output Context">
    Choose between custom separators and newlines based on where the output will be used - commas for CSV data, newlines for readable lists, spaces for sentences.
  </Step>
</Steps>

### Troubleshooting

<AccordionGroup>
  <Accordion title="Why is my output empty?">
    This occurs when the input text list is empty or not connected properly.
    
    <Tip>Check that your text list input is connected and contains at least one item</Tip>
    
    Verify: 1. Text list input is connected to a block that outputs text items 2. The source block is producing a non-empty list 3. All text items in the list contain actual content
  </Accordion>

  <Accordion title="My separators aren't showing up correctly">
    The join characters might be overridden by the "Join By New Line" setting, or special characters may need proper formatting.
    
    ```text Example Solutions wrap
    For commas: ","
    For comma-space: ", "
    For pipes: " | "
    For tabs: "\t"
    ```
    
    <Warning>When "Join By New Line" is enabled, it takes priority over custom join characters</Warning>
  </Accordion>

  <Accordion title="How do I create bulleted or numbered lists?">
    Use the join characters field to add list formatting to each item.
    
    ```text Bulleted List Example wrap
    Join Characters: "\n• "
    Result: • Item 1
    • Item 2
    • Item 3
    ```
    
    <Info>For numbered lists, consider using a different block to add numbers before joining</Info>
  </Accordion>

  <Accordion title="Can I join non-text data types?">
    This block only works with text (string) arrays. Other data types need to be converted to text first.
    
    <Tip>Use appropriate conversion blocks (like JSON stringify) before joining if you have numbers, objects, or other data types</Tip>
  </Accordion>
</AccordionGroup>
