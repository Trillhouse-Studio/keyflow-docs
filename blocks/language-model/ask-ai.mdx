title: Ask AI
---

### Overview

Send prompts to AI models and get responses. Choose from various models including GPT, Claude, and others. Supports structured outputs, reasoning modes, and response caching.

<Tip>The Ask AI block is your gateway to AI-powered responses.</Tip>

---

### Inputs

<ParamField query="Prompt" type="String" required>
  The prompt to send to the AI model. This is the main instruction or question
  you want the AI to respond to.
</ParamField>

<ParamField query="Model" type="String" default="GPT-4o Nano">
  AI model to use for generating the response. Different models have varying
  capabilities, costs, and speed.
</ParamField>

<ParamField query="Structured Output" type="Boolean" default="false">
  Allows you to create structured outputs. When enabled, the AI will return data
  with predefined Response Schema instead of free-form text.
</ParamField>

<br></br>

<Accordion title="Advanced Settings">
  <ParamField query="Response Schema" type="Object">
    Define the schema for structured output. Only appears when Structured Output
    is enabled. Defines the exact JSON structure you want the AI to return.
  </ParamField>

<ParamField query="Reasoning Effort" type="String" default="low">
  Reasoning level for O1 models. Options: `low` (faster, cheaper), `medium`
  (balanced), `high` (thorough reasoning, slower). Only appears when using O1
  family models.
</ParamField>

<ParamField query="Thinking Budget" type="String" default="1024">
  Maximum tokens for reasoning (Claude 3.7 Sonnet only, minimum 1024). Controls
  how much internal reasoning the model can perform.
</ParamField>

<ParamField query="Account" type="String">
  API credentials to use. Select specific API keys instead of using the default
  account credentials.
</ParamField>

  <ParamField query="Cache Response" type="Boolean" default="true">
    Cache the response for future use. When enabled, identical requests will
    return cached results to save costs and improve speed.
  </ParamField>
</Accordion>

### Outputs

<ParamField query="Response" type="String/Object">
  AI model response. Returns as String for regular output or structured Object
  when Structured Output is enabled.
</ParamField>

<br></br>

<Accordion title="Additional Outputs">
  <ParamField query="Cost" type="String">
    Cost of the API call in credits or currency units.
  </ParamField>

<ParamField query="Reasoning" type="String">
  Model's reasoning process. Only available when using Claude 3.7 Sonnet with
  Thinking Budget enabled.
</ParamField>

<ParamField query="Input Tokens" type="String">
  Number of input tokens used in the API call.
</ParamField>

<ParamField query="Output Tokens" type="String">
  Number of output tokens generated by the model.
</ParamField>

  <ParamField query="Model" type="String">
    The actual model used for the request (reflects the selected model).
  </ParamField>
</Accordion>

### Best Practices

<Steps>
  <Step title="Craft Clear, Specific Prompts">
    Write detailed instructions instead of vague requests. Include context,
    desired format, and specific requirements.

    ```text Vague Prompt
    Analyze this data
    ```

    ```text Clear Prompt wrap
    Analyze this sales data and provide 3 key insights about customer behavior, 2 concerning trends, and specific recommendations for Q4 strategy
    ```

  </Step>
  <Step title="Choose the Right Model">
    Match model capability to task complexity and budget: 
    - **GPT-4o Mini**: Simple tasks, cost-effective 
    - **O1 Models**: Complex reasoning with adjustable effort levels 
    - **Claude 3.7 Sonnet**: Deep analysis with reasoning visibility
    </Step>

  <Step title="Optimize Performance & Cost">
    Enable response caching for repeated queries 
    - Use structured output for consistent data formats 
    - Adjust reasoning effort based on task complexity 
    - Test with smaller models before using premium ones
  </Step>
</Steps>

### Troubleshooting

<AccordionGroup>
  <Accordion title="Why is my structured output not working?">
    Ensure both conditions are met:
    1. **Structured Output** checkbox is enabled
    2. **Response Schema** is properly defined with valid JSON Schema format
    
    ```json title="Valid Schema Example"
    {
      "type": "object",
      "properties": {
        "field_name": {"type": "string"},
        "field_number": {"type": "number"}
      },
      "required": ["field_name"]
    }
    ```
  </Accordion>

    <Accordion title="How can I reduce API costs?">
    <Tip>**Cost Optimization Strategies** 💰</Tip>
    - Use **GPT-4o Mini** for simple tasks instead of premium models
    - Enable **Cache Response** for repeated similar queries
    - Write concise, clear prompts to reduce token usage
    - Choose appropriate **Reasoning Effort** levels (start with "low")
    - Test prompts with smaller models before scaling up
    </Accordion>

    <Accordion title="What's the difference between reasoning effort levels?">

        **Reasoning Effort** (O1 models only):
            - **Low**: Faster processing, lower cost, good for straightforward questions
            - **Medium**: Balanced approach, suitable for most analytical tasks
            - **High**: Maximum reasoning depth, higher cost, best for complex problems

    <Warning>
        Higher reasoning effort significantly increases both processing time and
        costs
    </Warning>
    </Accordion>

    <Accordion title="Why am I getting authentication errors?">
        Check your API credentials:
            1. Verify you've selected valid credentials in the **Account** field
            2. Ensure your API keys haven't expired
            3. Check if you havesufficient quota/credits
            4. Contact your administrator to verify API accesspermissions
    </Accordion>

  <Accordion title="Can I use custom or fine-tuned models?">
    The Ask AI block supports all models available in your Keyflow account. Custom models need to be:
        1. Configured at the account level first
        2. Added to your organization's model list
        3. Properly authenticated with required credentials
    
    <Info>Contact your Keyflow administrator to add custom models to your account</Info>
  </Accordion>
</AccordionGroup>
